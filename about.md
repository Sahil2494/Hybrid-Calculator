🚀 Features

Standard Operations:

Addition, subtraction, multiplication, division, parentheses, and decimal handling.

Scientific Operations:

Factorial (using Lanczos approximation), square roots, exponentiation and factorials.

Constant : 
pi

Expression Parsing Engine:

Built using the Shunting-Yard algorithm to convert infix expressions to postfix, followed by a postfix evaluator.
